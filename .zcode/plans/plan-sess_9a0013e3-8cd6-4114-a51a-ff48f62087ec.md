# NixOS 配置仓库结构重构(修订版)

在新建分支 `refactor/structure` 上进行,全程 `git mv` 保留历史,完成后校验评估,不提交。

## 新结构

```
flake.nix / flake.lock / README.md / .gitignore
target/
  zenbook/
    configuration.nix           # 入口:imports + 主机身份(时区/网络/用户/HM 块)
    system/                     # 本机全局配置(基础设施)
      hardware-configuration.nix
      boot.nix
      nixos.nix                 # nix 设置/nh/GC/电源/显卡
      proxy.nix                 # 保持未启用
    home/
      default.nix               # 入口(原 tuf3i.nix)
      shell.nix                 # zsh/direnv/fzf 等 HM 配置
      tools.nix                 # git 身份+签名、delta 等 HM 配置(包列表拆走)
      apps.nix / gpg-ssh.nix
modules/                        # 共享模块库,供各 target 按需导入
  cli/                          # 每个 CLI 工具一个 名称.nix 单文件
    git.nix  neovim.nix  curl.nix  wget.nix          # root 应急四件套(原 tool.nix 拆分)
    fastfetch.nix  btop.nix  eza.nix  tldr.nix  ripgrep.nix  fd.nix
    unzip.nix  wl-clipboard.nix  gcc.nix  tree-sitter.nix    # AstroNvim 依赖
    nixd.nix  nixfmt.nix  gitmoji-cli.nix                    # 开发工具
    claude.nix  zcode.nix  zsh.nix   # zsh.nix 即原 core/shell.nix(系统级 zsh)
  gui/    browser.nix  libreoffice.nix  fcitx5.nix
  desktop/ niri.nix  dms.nix  greeter.nix
  service/ clash-rev.nix  zerotier.nix
```

## 具体操作

1. **建分支**:`git checkout -b refactor/structure`
2. **git mv 移动**:host/pc.nix→target/zenbook/configuration.nix;hardware-configuration、core/{boot,nixos,proxy}→target/zenbook/system/;home/*→target/zenbook/home/(tuf3i.nix→default.nix)
3. **CLI 工具拆单文件**:原 core/tool.nix(git/wget/curl/neovim)与 home/tools.nix 的包列表(fastfetch/btop/eza/tldr/ripgrep/fd/gcc/unzip/wl-clipboard/nixd/nixfmt/gitmoji-cli/tree-sitter)全部拆为 modules/cli/<名称>.nix,每个文件只装该包(系统级 systemPackages,root 也可用);core/shell.nix 改名 zsh.nix;claude/zcode 原样迁入
4. **desktop 类别**:niri/dms/greeter 进 modules/desktop/;gui/ 只留 browser/libreoffice/fcitx5
5. **删除**(已确认):terminal.nix(空)、mihomo.nix(纯注释占位)
6. **更新 imports**:
   - configuration.nix 重写:system/ 四个文件 + modules 按类逐个导入(cli 按上面清单逐个)
   - flake.nix:`./target/zenbook/configuration.nix`;HM 块 `import ../home`
   - home/tools.nix 删掉 home.packages 列表(已拆去 modules/cli),保留 git 签名/delta 等 HM 配置
7. **检查 `result` 软链**:若仍被 git 追踪则移出
8. **README.md** 重写为新结构

## 验证

`nix eval` 顶层 derivation + 构建 HM activationPackage(不挂代理,走 TUN),零错误零警告;文件内容除 imports 路径与包位置外逻辑零改动。

## 语义变化说明

- fastfetch/btop/eza 等从 home.packages 改为系统级安装:所有用户(含 root)可用,PATH 同样生效,无实际使用差异
- git/neovim 包在系统级(cli 单文件)与 HM 配置(身份/签名/编辑器行为)分工明确

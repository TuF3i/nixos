# NixOS 配置:修复 + 优化 + 启用 home-manager

原则:系统层(NixOS modules)管包和服务、保证 root 也能用;$HOME 下的配置文件(zsh/git/ghostty 等)交给 home-manager。不执行任何 rebuild/git 命令,只写文件。

## 一、启用 home-manager

**1. `flake.nix`**
- 移除未使用的 `quickshell`、`catppuccin` input(`home-manager`、`llm-agents` 保留,均有引用)
- modules 列表加入 `inputs.home-manager.nixosModules.home-manager`

**2. `host/pc.nix`**
- 加 home-manager 配置块:`useGlobalPkgs = true; useUserPackages = true; extraSpecialArgs = { inherit inputs; };`,`users.tuf3i = import ../home/tuf3i.nix;`
- 删掉空的 `packages = with pkgs; [ ]`

**3. `home/tuf3i.nix`(新建)** — 入口:username/homeDirectory,`home.stateVersion = "26.05"`,imports 下面三个模块

**4. `home/shell.nix`(新建)** — 接管用户 shell(同时修复 shellInit 问题):
- `programs.zsh`:enableCompletion、autosuggestion、syntaxHighlighting、history(size 10000 / ignoreDups / share)
- `programs.direnv`:enable + nix-direnv(替代手写 eval hook)
- `programs.fzf`:enable
- `home.sessionVariables`:EDITOR/VISUAL = "nvim"

**5. `home/tools.nix`(新建)**
- `programs.git`:enable + delta + extraConfig(init.defaultBranch = "main"、push.autoSetupRemote = true),userName/userEmail 留注释占位由你填
- `programs.neovim`:enable、defaultEditor、viAlias、vimAlias
- `home.packages`:fastfetch、btop、eza、tldr、ripgrep、fd

**6. `home/apps.nix`(新建)**
- `programs.ghostty`:enable + settings(font-family = "FiraCode Nerd Font"、font-size = 12、theme = "catppuccin-mocha")

**7. `modules/core/shell.nix`** — 只留 `programs.zsh.enable = true;`(系统级 zsh 基础设施),原有 shellInit 移除(即修复"hook 写进 /etc/zshenv"的问题)

**8. `modules/application/terminal.nix`** — ghostty 已迁至 home/apps.nix,文件留空占位注释

## 二、修复项

**9. `modules/application/browser.nix`** — 修正 Chrome flags:
- 把 `"--enable-wayland-ime --wayland-text-input-version=3"` 拆成两个独立参数(fcitx5 正常工作的关键)
- 两个 `--enable-features` 合并为 `UseOzonePlatform,WaylandWindowDecorations`(避免后者覆盖前者)
- 删掉与 `--ozone-platform=wayland` 重复的 `--ozone-platform-hint`

**10. `.gitignore`(新建)** — `result` / `result-*`

## 三、优化项

**11. `modules/core/nixos.nix`**
- `programs.nh.flake = "/home/tuf3i/nixos"`(让 `nh os switch` 直接可用)
- `nix.settings.auto-optimise-store = true`
- `nix.gc`:weekly 自动清理 14 天前旧 generation(已确认开启)
- 新增:`services.power-profiles-daemon`(DMS 电源面板依赖)、`services.thermald`(Intel 笔记本温控)、`hardware.graphics.enable` + `intel-media-driver`(视频硬解)
- 移除无作用的 `cups-pk-helper`(未启用打印服务)

**12. `modules/core/boot.nix`** — `boot.loader.grub.configurationLimit = 10;` 防止旧 generation 挤爆 /boot

**13. `modules/desktop/dms.nix`**
- 修复 16-38 行的整体缩进
- fonts.packages 补 `noto-fonts`、`noto-fonts-cjk-sans-serif`、`noto-fonts-emoji` —— 目前系统是 zh_CN + fcitx5 但没装任何中文字体,中文会显示豆腐块

**14. `modules/core/tool.nix`** — 保留 git/wget/curl/neovim(系统级,root 应急可用);移除 fzf、fastfetch(改由 home-manager 提供,避免重复)

**15. `README.md`** — 重写:目录结构说明 + 常用命令(nh os switch、垃圾清理说明)

## 不动的文件

hardware-configuration.nix、fcitx5.nix、claude.nix、zcode.nix、niri.nix、proxy.nix(保持未启用)、mihomo.nix(占位)、dms/fcitx5 现有功能逻辑

## 需要你之后手动做的

1. `git rm --cached result`(把误提交的软链移出版本库;.gitignore 只对未跟踪文件生效)
2. 若 `~/.zshrc`、`~/.gitconfig` 或 ghostty 配置目录里有手工维护的旧文件,首次 `nh os switch` 时 home-manager 会因文件冲突激活失败,先备份移走
3. `sudo nixos-rebuild test --flake /home/tuf3i/nixos#zenbook` 或 `nh os test` 验证

如允许,我写完后会用 `nix eval` 做一次纯静态校验(不 rebuild、不切换),确保 option 名无误。
